# ⚙️ API Cuidarte+

API REST en Express y PostgreSQL. Para instalación, despliegue y advertencias de seguridad consultar [README principal](../README.md).

- Swagger UI: `/docs`
- OpenAPI JSON: `/openapi.json`
- Variable de base de datos: `DATABASE_URL`
- Comando: `npm start` desde la raíz o desde `BACKEND`

**Advertencia:** código académico; antes de publicar con datos reales deben corregirse contraseñas sin hash y revisarse permisos de acceso.
